# Career Starter：给Codex一个链接，开始自己的求职系统

Codex先了解你，再建立档案、制作简历、寻找适合的岗位，并维护投递进度。你可以提供旧简历，也可以直接讲经历；不要求先填完表格，不默认职业、学历或国家。

## 怎么开始

在Codex中发送这句话：

> 请读取这个GitHub项目：https://github.com/suoyff-afk/career-starter ，按README和AGENTS启动我的个人求职系统。先了解我的已有资料和求职要求，再建立私有档案、制作简历并寻找适合的岗位。不要替我投递或联系企业。

Codex在获准的本地工作目录获取项目，读取执行入口，然后询问关键资料。已经下载时，在Codex打开项目，说“按AGENTS启动我的求职系统”即可。不知道目标职位时，先根据真实经历一起确定方向；已有资料能回答的问题不重复问。

需要Codex具备本地文件访问和联网检索能力。仓库未取得、招聘页打不开或本机不能编译时，明确缺少的步骤，不能冒称完成。

## 你得到什么

```text
workspace/                  # 私有资料，默认不提交Git
  profile.md                # 唯一背景档案与可复制申请文字
  rules.md                  # 求职方向、搜索渠道、复查安排
  tracker.md                # 已投递 / 行动批 / 其他考虑项
  resume/
    resume.tex              # 可编辑简历正文
    resume.pdf              # 本地LaTeX编译生成
    .build/compile.log      # 最近一次编译诊断
```

有实际内容再添加以下位置，不由init预建空目录：

| 可选位置 | 用途 |
| --- | --- |
| workspace/materials/ | 使用者提供的原件；这是目录，不是materials.md |
| workspace/companies.md | 一张岗位比较表：综合评分、公司、岗位名称（招聘链接）、推荐理由、差距与申请注意 |
| workspace/companies/公司名/ | 仅实际HR沟通、面试邀约或明确后续安排后建立，基础面与终面分开 |
| workspace/attachments/公司名/ | 必要企业表格与附件，收到附件不等于需要独立公司档案 |

tracker只管进度与下一步，companies只管判断，不复制两套状态。需要评分时，公司比较表按综合暂评分降序，未知置底；同轮使用一致的用户权重与可比依据，缺核心JD不硬给分，评分不阻塞准备；评分按使用者偏好制定，不照搬维护者的职业或权重。不另设冗长补充段落，必要条件放回表格；证据不足不硬评分。

维护时更新现有文件，去除重复解释、过期操作指令和无新路径的淘汰备选；保留已投事实、必要来源及简短排除理由。默认不设归档目录，不按公司复制简历，PDF和TeX必须对应保留。原件不改，清理前检查独有内容和引用，删除无用材料优先可恢复方式。

1. **了解你**：提取事实，补问目标、地区、到岗和关键经历；未知单列，不编成果。
2. **制作简历**：依据已提供资料先生成可审阅的共用TeX简历；只核对缺失、冲突及首次对外使用的关键事实，已确认内容不重问。栏目按经历选择，本地生成PDF并检查版式和文字。
3. **找岗位**：按职责与可迁移能力扩展公司范围，核官方完整JD、资格、差距、薪资来源与日期，给少量可执行机会。
4. **跟进复盘**：准备网申和面试材料，你确认投递后逐岗记账；只有要求并实际创建后才启用定时检索。

投递、联系企业、对外上传或发布由你决定。个人资料不能放公共仓库。无回复不直接解释为被拒。

## 随项目提供的三个Skill

Codex按AGENTS中的任务入口直接读取，不需要使用者安装或另填配置。

| Skill | 用途 |
| --- | --- |
| [job-crawler](skills/job-crawler/SKILL.md) | 发现并核实岗位 |
| [technical-job-search](skills/technical-job-search/SKILL.md) | 工程／科研岗位判断、申请材料和待遇比较 |
| [interview-rehearsal](skills/interview-rehearsal/SKILL.md) | 面试稿、逐题练习和复盘 |

例如说“帮我查这家公司的岗位”或“开始面试练习，一题一题来”。技能只提供方法，不包含任何人的履历；文件归属与权限统一按AGENTS执行。不为使用这些技能复制第二份背景或总表。

## 本地工具

下面命令由Codex执行，使用者无需手工操作。辅助脚本需要Python 3.10或以上（仅标准库），简历用本地XeLaTeX（TeX Live或MiKTeX）。不需要数据库、付费API或强制安装求职Skill。脚本只负责建档和编译；访谈、修改简历和岗位检索由Codex执行，不是运行脚本后自动完成。

```sh
python scripts/career.py init
python scripts/career.py build
```

从仓库根目录运行；也可在命令后指定私有工作区路径。`init`只补缺失文件；`build`阻止占位字段残留、失败保留原PDF，诊断写入`.build/compile.log`。`--draft`仅用于排版草稿。PDF生成后仍需事实、目检和文字核对，不等于ATS已通过。

没有Python时按模板直接建档；没有XeLaTeX或字体/宏包时先检查实际环境和日志，按授权补依赖，不静默改成HTML。中文字体有Windows优先及TeX字体回退，跨系统实际效果需要验证。
